# Media plan

The site is intentionally image-light until approved assets are available. Do not use stock imagery for research or project claims.

| Project | Recommended primary media | Optional supporting media |
| --- | --- | --- |
| REASONATE | Abstract systems / testing diagram approved for public use | Architecture or evaluation visual |
| EPO CodeFest | Approved team or ceremony photograph | Interface screenshot with data redacted as needed |
| Project MUSA | Payload, ground station, or flight-preparation photograph | Poster, monitoring or embedded hardware image |
| CERN LHCb | Approved CERN/LHCb working image | Diagram or code/performance visual with permission |
| NRAO / VLASS | Survey quicklook image | Presentation or outreach image |
